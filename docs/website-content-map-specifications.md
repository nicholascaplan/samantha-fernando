# Legacy Site Content Map

This is a concise reference to the pre-redesign website. It is not a specification for the current site and must not override `docs/content.md`.

## Retired Structure

The original site used separate pages for Home, Events, Past Performances, Works List, Watch, Listen, Writing, Current, Rising, glass human, Wintering and Contact.

## Content Reused In The Current Site

- Biography, education, collaborators and selected highlights.
- Works catalogue, instrumentation, commissions and premiere information.
- Recordings, film links, writing and contact details.
- Project material for Current, Rising, glass human and Wintering.

## Current Mapping

| Legacy area | Current location |
| --- | --- |
| Home and Biography | `/` and `/biography/` |
| Works, Listen and Watch | Shared Works & Media catalogue |
| Events and Past Performances | Content archive only, not public UI |
| Dedicated project pages | Spotlight, Biography and catalogue context |
| Writing and Contact | `/writing/` (including the full essay) and `/contact/` |

For current copy, metadata, media URLs and detailed catalogue records, use `docs/content.md`. For missing or disputed content, use `docs/questions-for-sam.md`.
